# 毛孩日誌 Pet Care Diary

給忙碌毛孩家長的寵物照護紀錄工具。單一 HTML 檔，不需後端、不需登入，資料存在瀏覽器 localStorage（約 5MB，照片會壓縮）。

## 使用
直接用瀏覽器開啟 `index.html`（或部署到 GitHub Pages 後用手機開啟，可「加入主畫面」）。

- **首頁**：寵物卡、霓虹光環倒數、今日待辦、皮膚發紅警示、快速預約
- **時間軸**：依類別 / 寵物篩選的歷史紀錄
- **行事曆**：月曆標示已完成（實心點）與待辦提醒（空心圈），可匯出 `.ics` 到手機行事曆
- **統計**：寵物身分卡、體重趨勢、年度開銷圓餅圖與每月開銷
- **設定**：寵物資料、各類別週期天數、常用店家（電話 / LINE）、JSON 備份匯出匯入

資料只存在本機瀏覽器，換手機或清除瀏覽器資料前請先匯出 JSON 備份。
