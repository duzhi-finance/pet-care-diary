# 毛孩日誌 Pet Care Diary

給忙碌毛孩家長的寵物照護紀錄工具。單一 HTML 檔，不需後端、不需登入，資料存在瀏覽器 localStorage（約 5MB，照片會壓縮）。

## 使用
直接用瀏覽器開啟 `index.html`（或部署到 GitHub Pages 後用手機開啟，可「加入主畫面」）。

- **首頁**：毛孩名牌卡、今日提醒、全部毛孩總覽、急診專區、照護倒數圓環（點擊即預約）、今日待辦、皮膚發紅警示、飼料與消耗品倒數
- **毛孩隨身卡**：正反面翻轉卡片，背面為緊急就醫卡（QR Code、血型、過敏、用藥、疫苗與緊急聯絡）；可下載為 PNG。為個人紀錄，非官方文件
- **時間軸**：依類別 / 寵物篩選；照片標記「送洗前 / 完成後」會並排呈現 Before / After
- **交接備忘**：送洗、寄養或請人照顧時，一鍵產生毛孩注意事項純文字，可複製或傳到 LINE
- **行事曆**：已完成、待辦、逾期與消耗品用完日；「分享行程」可把未來 30 天行程複製成純文字或傳到 LINE
- **統計**：體重趨勢（含目標體重虛線）、年度開銷圓餅圖與每月開銷
- **設定**：字級大小（標準 / 大 / 特大）、寵物資料、飼主聯絡、各類別週期、常用店家、JSON 備份匯出匯入

產品介紹頁位於 `intro/index.html`（部署後為 `/intro/`）。

資料只存在本機瀏覽器，換手機或清除瀏覽器資料前請先匯出 JSON 備份。
